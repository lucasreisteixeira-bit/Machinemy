# machinemy

Interface visual do sistema **machinemy** — Gestão Inteligente de Estoque.

## Tecnologias

- React 18
- Vite
- React Router
- CSS próprio (sem frameworks de UI)

## Como executar

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`

## Rotas

| Rota | Descrição |
|------|-----------|
| `/login` | Tela de login (página inicial) |
| `/dashboard` | Dashboard principal |
| `/produtos` | Produtos (placeholder) |
| `/alertas` | Alertas (placeholder) |
| `/entrada` | Entrada de produtos |
| `/saida` | Saída de produtos |
| `/conta` | Conta |
| `/cadastro` | Cadastro |
| `/mais-vendidos` | Mais vendidos |
