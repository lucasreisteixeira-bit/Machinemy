MACHINEMY - atualização visual e funcional

Incluído:
- Dashboard inicial com cards, movimentações recentes, ranking e tema claro/escuro.
- Página Alertas de estoque com filtros, tabela, resumo e recomendações.
- Página Entrada de produtos funcional: registrar entrada aumenta o estoque.
- Página Saída de produtos funcional: registrar saída reduz o estoque.
- Página Mais vendidos com gráfico e cards de resumo.
- Página Produtos funcional, com cadastro, busca, filtros, excluir e trocar imagem.
- Página Minha conta mantida.
- Mascote oficial em PNG.
- Dados persistidos em localStorage enquanto não há banco de dados.
- HashRouter + configuração de GitHub Pages.
- Workflow do GitHub Actions em .github/workflows/deploy.yml.
- Aba Cadastro removida, pois cadastro de produto fica em Produtos.
