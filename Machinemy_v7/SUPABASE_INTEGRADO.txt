MACHINEMY + SUPABASE

Esta versão usa o projeto Supabase machinemy para:
- autenticação real por e-mail e senha;
- produtos online;
- edição e exclusão de produtos;
- entradas e saídas;
- perfil do usuário;
- imagens de produtos no Storage.

Banco criado:
- public.products
- public.entries
- public.exits
- public.profiles

Storage:
- bucket product-images (público para leitura; escrita apenas autenticada)

Segurança:
- RLS habilitado nas tabelas públicas;
- usuários não autenticados não podem ler/escrever estoque;
- perfis só podem ser lidos/alterados pelo próprio usuário;
- nenhuma service_role/secret key está no frontend.

Primeiro acesso:
1. Abra o site.
2. Clique em "Criar uma conta".
3. Informe nome, e-mail e senha.
4. Se o Supabase exigir confirmação de e-mail, confirme a mensagem recebida.
5. Faça login.

GitHub Pages:
- O projeto já contém a URL e a publishable key do Supabase (a publishable key é própria para uso em frontend com RLS).
- O workflow usa npm install para instalar @supabase/supabase-js antes do build.
