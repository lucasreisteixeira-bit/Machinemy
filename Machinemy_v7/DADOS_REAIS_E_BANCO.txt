MACHINEMY - VERSÃO DADOS REAIS

Esta versão não possui produtos, entradas, saídas, ranking ou alertas fictícios.
Tudo é calculado a partir do que você cadastrar.

ATUALMENTE:
- os dados ficam no localStorage do navegador;
- Produtos usa somente seus cadastros;
- Entrada aumenta o estoque real do produto;
- Saída diminui o estoque real do produto;
- Alertas usa estoque mínimo e validade reais;
- Mais vendidos usa as saídas registradas;
- Dashboard usa produtos e movimentações reais;
- Conta pode ser preenchida com seus próprios dados.

PRÓXIMO PASSO: SUPABASE
Para os mesmos dados aparecerem em qualquer computador, conectar ao Supabase.
Tabelas planejadas:
- products
- entries
- exits
- profiles

As credenciais do Supabase NÃO devem ser colocadas diretamente no código público.
Usar variáveis VITE_SUPABASE_URL e VITE_SUPABASE_PUBLISHABLE_KEY.
